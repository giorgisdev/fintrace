# Fintrace

> Early development

Bookkeeping software for local businesses. Upload receipts, invoices, bank statements and other transactional documents. Fintrace extracts data from image files and PDFs to automate the process of calculating expenses and payroll.

# core focus
Helping businesses track numbers across scattered documents. Fintrace turns PNG, JPG, and PDF documents into searchable, structured transactions, linked to the original image.

# early-stage features
- Document analysis: extract transactions from receipts, bank statements and invoices (PNG first, then PDF)
- Invoice tracking: create, track and mark invoices paid

Early architecture stage. See [`scaffold.md`](scaffold.md) for the plan.
